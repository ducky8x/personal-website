Machine Learning 2048

The story of how I used machine learning to solve 2048.

What is 2048?

2048 is a simple game in which you merge tiles with the same number in a 4–by–4 grid to make bigger ones. You keep going until you reach the 2048 tile. I chose this game because I felt that it was a simple enough game to train on, while also having various strategies I wanted to test.

Fun fact: the original game of 2048 was written in JavaScript and CSS over a weekend. (Wikipedia)

How I pulled it off:

I trained a reinforcement learning model to play the game. It learns by playing the game over and over and learning from its mistakes. I ran my model thousands of times for it to be able to consistently beat the game.
