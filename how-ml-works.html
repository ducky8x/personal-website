How ML Works

A standard computer program follows rules a person wrote. A machine learning program, however, learns from its environment and gets better.

Three Ways Machines Learn
Type How It Learns Examples
Supervised From examples that come with the right answer The "Cat or Dog?" question
Unsupervised By finding patterns on its own, with no answers given Clustering, pattern detection
Reinforcement By trying things and getting rewards or penalties A model playing a game
Disclaimer: The examples shown are simplified groupings of ML. In reality, there are many more types of ML that I will not cover in this site.

This site will focus on reinforcement learning, because that's how my agent learns.
